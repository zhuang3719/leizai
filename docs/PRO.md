# Lite 与 Pro 的边界

雷仔采用 **Lite（开源）+ Pro（闭源私模）** 双形态。本仓发布的是 **Lite（Apache-2.0）**，
包含完整可运行的引擎与界面；Pro 能力通过**独立的闭源子进程**（`leizai-pro.exe`）承载，
**不在本仓**。

## 一、设计原则（方案 B）

- **开源引擎零第三方依赖**：Pro 不以 `.node`/WASM 形式嵌入，而是**独立子进程** + stdio 长度前缀 JSON-RPC。
- **私模缺失 = Lite**：引擎 `src/pro/gate.js` 在缺少私模时**降级为 Lite，绝不崩溃**。
- **不把本地能力强行服务端化**（不做第 3 层）：本地能力以"闭源壳门 + 私模校验 + manifest 互校 + 服务端 license/设备绑定/心跳"组合**抬高破解成本**，
  承诺"**堵死顺手白嫖 + 破解后降级不崩**"，**不承诺"不可绕"**（对齐"不防有心破解"）。

## 二、Pro 能力清单与"守在哪一层"

| Pro 能力 | 守层 | 说明 |
|---|---|---|
| 云增值能力（云端模型 / 云同步 / 云编排等，未来） | **服务端真值（不可绕）** | 天然联网，白嫖者拿不到云端功能 |
| 不限量多角色 | **本地能力**：闭源壳门 + 私模校验 + 服务端 license 心跳 | 本地算法，承认"有心破解可绕" |
| 自我进化 | 同上 | 同上 |
| 无限记忆 | 同上 | 同上 |

- **服务端真值能力**：要求"本地不可绕"。
- **本地能力**：组合防线抬高成本，**破解后降级不崩、无真 Pro 输出**。

## 三、Ed25519 验签公钥（`docs/manifest.pub`）

- 用途：校验 **Pro 完整性 manifest**（`pro/manifest.json`）的 **Ed25519 签名**，以及授权 token 的验签。
- 公钥（SPKI, base64）见本目录 `manifest.pub`：`MCowBQYDK2VwAyEAd7iqqY1dI9nvv/HjzEuKga1P/+SukcqSRbzlTAtpCUI=`
- 启动互校：引擎用该公钥验签 manifest，逐文件 sha256 互校；**校验失败即降级，不崩溃**。
- ⚠️ **私钥绝不入库**：私钥仅存于**离线构建机**与服务端 secret，本仓只含公钥。

## 四、授权 token（简述）

- 格式（单一权威）：两段式 `b64url(payload).b64url(sig)`，签名对象 = payload 的 b64url 串（Ed25519）。
- 私模通过 stdio JSON-RPC 暴露 `handshake / pro.check / ping`；一次性 `PRO_TOKEN` 经 env 与握手帧双通道送达，两者一致才认授权。
